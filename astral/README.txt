カード収集・CPU対戦版

パソコンで遊ぶ
ZIPを展開し、index.htmlをブラウザーで開きます。
マウスでカードを引っぱり、押し続けると詳細が開きます。
キーボードではTabでカードを選択、Enterでつかみ、
矢印キーで対象を選んでEnterで実行します。Iキーでカードの詳細が開きます。

iPhoneで遊ぶ
1. パソコンとiPhoneを同じWi-Fiにつなぎます。
2. 展開したindex.htmlのあるフォルダをパソコンで開き、
   Python 3が入っている場合は次のコマンドを実行します。

   python3 -m http.server 8765 --bind 0.0.0.0

   Windowsでpython3が使えない場合は、代わりに
   py -3 -m http.server 8765 --bind 0.0.0.0
   を実行します。
3. iPhoneのSafariで、パソコンのローカルIPアドレスと8765番ポートを開きます。
   例　http://192.168.1.10:8765/
4. Safariの共有メニューから「ホーム画面に追加」し、追加したアイコンを縦向きで
   開くと画面いっぱいに遊べます。パソコンの配信は起動したままにします。

対戦とカード
操作と対戦ルールは、タイトル画面または対戦メニューの「遊び方」にあります。
最初のデッキは22枚。対戦に勝ったら、報酬のカードをタップしてめくります。
図鑑では入手したカードを、デッキ編成ではカードごとの編成枚数と所持枚数を確認できます。
「−」でカードを抜き、「＋」で追加します。22枚になったら「デッキを保存」を押します。
同じカードは3枚まで、金と虹の同じカードは1枚までデッキに入れられます。
手札の「傷２」は2ダメージ、「癒４」は4回復、「剣＋２」は攻撃力が2上がる印です。
カードの詳しい効果や対象は長押しで確認できます。

カードと編成、対戦記録、音の設定は同じブラウザー・同じアドレスで保存されます。
同じアドレスに試遊版の保存がある場合、獲得済みの報酬と音の設定を読み込みます。
ネット上のサービスへの接続は不要です。
