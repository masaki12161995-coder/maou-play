# 札の卓　ルール説明

スマホのブラウザで遊ぶ、2人対戦のカードゲームです。
`online.html` をブラウザで開くと遊べます（CPU戦は、この端末だけで遊べます）。

## 遊び方の流れ
1. 最初の画面で「部屋をつくる」か「部屋に入る」（6文字の合言葉）を選ぶと、友だちと対戦できます。「CPUと勝負」（よわい・ふつう・つよい）を選ぶと、CPUと対戦できます。
2. お互いに、240枚の札の中からでたらめに5枚ずつ引きます（それぞれ別々に引くので、同じ札がお互いの手札に入ることもあります）。お互いの手札は見えません。
3. 配られた手札は、1回だけ配り直せます（「引き直す」）。決まったら「これで勝負」。
4. コインを投げて、先攻・後攻を決めます。
5. 3×3の盤に、交互に手札から1枚ずつ置いていきます。札は、空いているマスに指で引っぱって置きます。
6. 盤の9マスが全部埋まったら終わりです。

## 勝ち負け
- 点数＝「盤の上の自分の色の札の数」＋「手札に残っている札の数」。
- 先攻は5枚、後攻は4枚を置くので、後攻は最後に手札が1枚残ります。はじめはどちらも5点です。
- 終わったときに点数の多いほうが勝ち。同じなら引き分けです。

## 札
- 札には、上・右・下・左の4つの数字（1〜10）があります。くせで上がると、10より大きくなることもあります（下がっても1より小さくはなりません）。
- 札には★1〜★6のレア度があります。枠の色は、★1〜3が白、★4が紫、★5が金、★6が虹色です。
- ★2〜★5の札の一部（72枚）は、ほかの魔物の色違いの姿で「色違いの札」と書かれています。強さは、その札の★のとおりです。
- 札の数：★1が43枚、★2が66枚、★3が59枚、★4が36枚、★5が25枚、★6が11枚。
- 多くの札は「くせ」（特別な力）を持っていて、札の下に名前が書いてあります。札をタップすると、くせの説明を見られます。

## 勝負（札の取り合い）
- 札を置くと、その札は、となりにある相手の札と勝負します。向かい合う辺の数字を比べます。
- 置いた札の数字のほうが大きければ、相手の札を取れます（自分の色に変わる）。同じ数字や小さい数字では取れません。
- 勝負を仕掛けるのは、置いた札だけです。すでに盤にある札は、自分からは勝負しません（くせで勝負する場合をのぞく）。
- 取られた札の数字は、そのままです。
- 1手の中では、置いた札の勝負 → 号令・連鎖などで続く勝負 → 吸収 → 仇討ち → 成長 → 執念 の順に起きます。

## くせの一覧

### 置く場所で強くなる
| くせ | 内容 |
|---|---|
| 角取り | 盤の四すみに置くと、4つの数字が全部＋1 |
| 真ん中 | 盤のまん中に置くと、4つの数字が全部＋2 |
| 縁取り | 四すみとまん中以外に置くと、4つの数字が全部＋1 |
| 一匹狼 | となりに味方の札がない所に置くと、4つの数字が全部＋2 |
| 群れ | 盤にいる味方1枚ごとに、4つの数字が全部＋1 |
| 先駆け | 盤に札が2枚までの、はじめのうちに置くと、4つの数字が全部＋2 |
| 後出し | 盤の空きが3マス以下の、終わりごろに置くと、4つの数字が全部＋2 |

### 試合の流れで強くなる
| くせ | 内容 |
|---|---|
| 逆境 | 点数で2枚以上負けているときに置くと、4つの数字が全部＋3 |
| 怒り | 手札にある間、味方が取られるたびに＋1 |
| 成長 | 盤に置いたあと、相手が札を置くたびに＋1（＋3まで）。育つのは、相手のその手の勝負が全部終わってから |
| 絆 | 盤に同じ★の味方がいるときに置くと、4つの数字が全部＋2 |
| 仇討ち | 味方の札が取られたとき、となりの相手ともう一度勝負する（相手の1手に1回） |

### 置いたときに働く
| くせ | 内容 |
|---|---|
| 号令 | 置いたとき、となりの味方が、もう一度となりの相手と勝負する |
| 威圧 | 置いたとき、となりの相手の数字を全部−1 |
| 博打 | 置いたとき、4つの数字がそれぞれ＋0〜＋5（運しだい） |
| 封印 | 置いたとき、となりの相手の札のくせを消す（それまでに上がった数字は、そのまま残る） |
| 斜め撃 | ななめの相手とも勝負する（こちらの一番大きい数字と、相手の一番小さい数字で）。辺どうしの勝負ではないので、鉄壁では防げない |
| 吸収 | 置いて取った札1枚ごとに、この札の数字が全部＋1（その手の勝負が終わってから上がる） |
| 回転 | 置くとき、いちばん多く取れる向きに回る |

### 比べ方が変わる
| くせ | 内容 |
|---|---|
| 同点勝 | 数字が同じでも、相手の札を取れる |
| 逆さ | この札から勝負を仕掛けるときは、数字が小さいほうが勝つ（攻められたときは、ふつうに大きいほうが勝つ） |
| 連鎖 | 取った札が、さらにそのとなりの相手とも勝負する（1回だけ。続けて取った札からは広がらない） |
| 王威 | 数字が同じでも取れて、取った札がさらにとなりとも勝負する（取った札は、その札自身のくせで勝負する） |

### 守り
| くせ | 内容 |
|---|---|
| 不屈 | 一度だけ、取られずにこらえる |
| 鉄壁 | いちばん大きい数字の辺から攻められても、取られない（その数字が2つ以上あれば、その全部の辺） |
| 道連れ | 取られたとき、取った相手の札もこちらの物になる（一度だけ） |
| 祟り | この札を取った札は、数字が全部−2 |
| 守護 | 盤にいる間、となりの味方の数字が全部＋1 |
| 執念 | 取られても、次の自分の番が来たときに戻ってくる。戻ったとき、4つの数字が全部＋1（一度だけ。最後の1手で取られたときは、もう番が来ないので戻らない） |

## 画面のこと
- 札を引っぱっている間は、置いたときの数字（くせで上がる分も含む）と、くせの名前が先に見えます。
- くせが働くと、金色でくせの名前が出ます。上がった数字は緑の↑、下がった数字は赤の↓で一瞬光ります。
- 勝負の場面では、勝つ数字が金色に光り、勝つ数字に↑、負ける数字に↓が付きます。
- 盤の数字は、守護で上がっている分も含めた「今の数字」です。
- 入口と手札の画面の右上にある音のボタンで、音を消せます。
